# nenmatsu-jumbo-checker

年末ジャンボ宝くじ / 年末ジャンボミニ 当せん判定网页。输入所持彩票的组和番号，即可对照已收录的开奖数据查看命中的奖项和金额。纯前端静态页面，不保存任何输入信息。

## 功能概览
- 支持年末ジャンボ、年末ジャンボミニ，已收录 2024、2025 年各回开奖数据，可切换回号或一键选择最新一回。
- 购买类型：バラ（单张）、連番（输入组和连号内任意一个 6 位番号，自动展开整组 10 连号）。
- 一次判定多张彩票；同一张命中多个奖项时全部列出，金额取其中最高奖。可按添加顺序、金额、组和番号排序。
- 查看当回当选号码列表；中奖时显示中奖动画和金额明细。
- 导入 / 导出：把号码列表编码成短文本，可复制、粘贴，或生成二维码 / 分享链接。
- 拍照识别组和番号（浏览器端 OCR，识别不稳定，需人工确认）。
- 界面语言：中文 / 日本語 / English；日间 / 夜间主题。

## 安装
无需构建，没有包管理依赖。拍照识别和二维码分别从 CDN 加载 `tesseract.js@5.0.5` 与 `qrcodejs@1.0.0`，首次使用需联网。

```bash
git clone https://github.com/Szyoo/nenmatsu-jumbo-checker.git
```

## 运行
页面通过 `fetch` 读取 `data/*.json`，不能用 `file://` 直接打开，需要起一个静态服务器：

```bash
cd nenmatsu-jumbo-checker
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

拍照识别依赖摄像头权限，仅在 `localhost` 或 HTTPS 下可用。在线版本：https://szyoo.github.io/nenmatsu-jumbo-checker/

## 用法
1. 选择种类和回号。
2. 选择购买类型，输入组（1～3 位）和番号（6 位数字），点「追加する」。
3. 点「判定する」查看结果。

### 判定规则
| 奖项 | 条件 |
| --- | --- |
| 指定组 + 番号（`exact`） | 组和番号都与当选号一致 |
| 组末位 + 番号（`mini_exact`） | 组的末位数字与指定数字一致，番号一致（Mini 的 1 等等） |
| 各组共通（`common_all_groups`） | 仅番号一致 |
| 后 n 位（`last_n_digits`） | 番号的后 n 位与指定数字一致 |
| 前後賞（Jumbo） | 与 1 等同组，番号为 1 等番号的前一位或后一位（范围 100000～199999 循环），奖金 1.5 亿日元 |
| 前後賞（Mini） | 组末位与 1 等一致，番号为 1 等番号的前后一位，奖金 1000 万日元 |
| 組違い賞（Jumbo） | 番号与 1 等相同、组不同，奖金 10 万日元 |

前後賞、組違い賞由 1 等号码自动推算，其金额写在 `main.js` 的 `checkWin` 中，不在数据文件里。

### 分享链接
`?import=<短文本>` 会在打开页面时自动导入号码列表。短文本每张彩票占 4 字节（组 10 位 + 番号 20 位），以 URL 安全的 Base64 编码；链接前缀由 `main.js` 中的 `SHARE_BASE_URL` 决定。

## 数据文件
`data/<年>_<jumbo|mini>_<回号>.json`：

```json
{
  "meta": { "year": 2025, "round": 1082, "type": "jumbo" },
  "prizes": [
    { "name": "1等", "type": "exact", "group": "022", "number": "146504", "amount": 700000000 },
    { "name": "5等", "type": "last_n_digits", "n": 3, "digits": "123", "amount": 10000 }
  ]
}
```

`type` 取值见上表；`mini_exact` 额外带 `group_last_digit`。新增一回开奖数据的步骤：
1. 按上述格式添加数据文件；
2. 在 `index.html` 的 `#round` 下拉框加一个 `<option>`（`value` 为文件名，不含 `.json`，并带 `data-type`、`data-year`、`data-round`）；
3. 在 `main.js` 三种语言的文案表里加对应的 `opt_<年>_<种类>` 条目。
